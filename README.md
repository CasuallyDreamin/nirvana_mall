# Nirvana Mall Website

A simple web-based project to showcase the Nirvana Mall, demonstrating front-end and back-end skills.

Built with **HTML, CSS, and JavaScript** to display mall features, shops, and interactive elements.

---

## Features

- Interactive sections to explore the mall.
- Responsive design for desktop and mobile.
- Clean layout to showcase skills and design sense.

---

## How It Works

- Navigate through the website to explore different sections of the mall.
- Each page highlights shops, services, or events.
- No backend or database required — purely static showcase.

---

## Running the Website

1. Clone the repository.
2. Open `index.html` in a browser.

---

## Files

- `index.html` → Main landing page
- `css/` → Stylesheets
- `js/` → JavaScript functionality
- `images/` → Images for the mall showcase
